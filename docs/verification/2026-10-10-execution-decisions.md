# Решения при выполнении

План: docs/superpowers/plans/2026-10-10-u-games.md.
База: 404dc900b631e7c8786be2399fa6590bf1f415ef.
Ветка: codex/ugames-mobile, отдельный managed worktree.

Все отступления от первоначального порядка/реализации:

1. Реальную награду перенесли из исследования в приёмку: сначала не удалось
   дойти до кнопки. Позже подтверждено 10 → 12 подсказок в Chrome и iOS.
2. JDK/Android SDK установлены в игнорируемую .tools: общий SDK недоступен для
   записи. Цена: дополнительное место и локальные пути инструментов.
3. Добавлен UIKit SceneDelegate: Xcode 27 отказался запускать приложение без
   scene lifecycle. Поддержка iOS 15 сохранена, добавлен один lifecycle-файл.
4. iOS popup синхронно наследует подготовленные protection controller/data store:
   WKUIDelegate не принимает асинхронный результат. Дочерние окна делят controller.
5. Экспериментальные помощники синтетических DOM-кликов удалены: они не вызывали
   реальную мобильную кнопку бонуса. Онлайн-проверка выполнена вручную обычным
   касанием; детерминированные интеграционные тесты остаются автоматическими.

Ревью: один независимый проход и одна серия исправлений четырёх Important.
Новых Critical не найдено. Проверки повторной инициализации, readonly init,
синхронной публикации SDK и iOS Retry добавлены после воспроизведения сбоев.

Приёмка частична: Android live за CAPTCHA; полный вход/прогресс и физическая
установка требуют участия владельца. Временный ledger сохранён в .superpowers,
поскольку эти пункты ещё открыты. SDK/JDK, снимки и сборки сохраняются локально.
