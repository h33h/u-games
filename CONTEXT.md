# U Games

Личный проект для игры в Яндекс Игры с телефона без рекламы.

## Термины

**Яндекс Игры**:
Существующий сервис Яндекса с каталогом и доступными в нём играми. В этом проекте подразумевается сам сервис, а не собственный каталог похожих игр.

**Без рекламы**:
Отсутствие любой рекламы как при выборе игры, так и во время игры, включая рекламу за награды.

**Награда за рекламу**:
Игровой бонус, который обычно предлагается за просмотр рекламы. В этом проекте пользователь получает такой бонус без просмотра рекламы.

**Весь каталог**:
Все игры, доступные пользователю в самом сервисе Яндекс Игры. Каталог приложения не ограничивается отдельной подборкой игр.
